# МИССИЯ: СПРАВЕДЛИВАЯ ОЦЕНКА

Образовательная игра для магистрантов по дисциплине «Педагогика высшей школы»: оценивание эффективности СРС и СРСП.

Откройте `index.html` либо запустите `python3 -m http.server 4173` и перейдите на http://localhost:4173. Сборки, регистрации, API и backend нет. Все сценарии, стили и данные доступны локально.

## Сценарий

1. Вступление, инструкция и карта с доступом к любому уровню.
2. 7.1: методы, критерии и оценка опоздавшего проекта четырьмя ползунками. Сумма из 20 не объявляется правильной или неправильной.
3. 7.2: выбор конструктивного отзыва и собственная обратная связь. Свободный текст сохраняется без автоматической оценки качества.
4. 7.3: пять ситуаций академической честности с контекстными объяснениями и счётчиком верных решений.
5. 7.4: выбор мер в бюджете 100 единиц, открытые коэффициенты модели и разбор стратегии.
6. Итоги, три вопроса рефлексии, краткие выводы и экспорт заметок.

## Баллы и управление

За завершение каждого этапа — 15 XP; за верный первый выбор в задании об обратной связи — 15 XP; за каждый верный судебный вердикт — 5 XP. Максимум 100 XP. Повторное подтверждение баллы не умножает. Игровые баллы не являются академической оценкой.

Вверху переключаются режимы игры и презентации. В презентации карточки теории раскрыты и увеличен текст. Стрелки переключают разделы; F открывает полный экран, Escape закрывает диалоги. Все элементы доступны клавиатурой. Есть таймер обсуждений. Система учитывает предпочтение уменьшенного движения.

Прогресс и заметки хранятся в localStorage текущего браузера. Хранилище старой презентации не затрагивается. Сброс новой миссии требует подтверждения. На экране итогов можно скачать состояние в текстовый файл. При запрете localStorage приложение продолжает работать в памяти.

## Публикация

Workflow `.github/workflows/pages.yml` публикует сайт при push в main. В GitHub: Settings → Pages → Source → GitHub Actions. Затем `git push -u origin main`. Необходима авторизация GitHub с правом записи в репозиторий. При обновлении страницы маршрут сохраняется в URL через hash; настройки сервера для маршрутов не нужны.

## Структура

- index.html — оболочка и диалоги.
- style.css — адаптивное оформление и анимации.
- mission-data.js — теория, кейсы и коэффициенты симулятора.
- app.js — маршруты, задания, сохранение и баллы.

Учебные показатели симулятора складываются с базовым значением 10 и ограничиваются 100. Это авторская условная модель, не эмпирический прогноз. Правила оценивания, сотрудничества и ИИ определяются конкретным курсом и вузом. Ссылки на материалы CMU и ICAI находятся в mission-data.js.
