# СРС / СРСП — От задания к результату

Интерактивный сайт-презентация на русском языке по теме «Оценивание эффективности СРС и СРСП».

## Содержание

- **7.1. Методы и критерии** — назначение оценивания, выбор методов, рубрика; оценка кейса по четырём критериям.
- **7.2. Самооценивание, взаимооценивание и рефлексия** — принципы и выбор конструктивной обратной связи, собственный отзыв.
- **7.3. Академическая честность** — источники, самостоятельность, границы помощи; три кейса с разбором.
- **7.4. Повышение эффективности** — этапы организации СРС и СРСП, показатели; выбор плана улучшений.
- Итоговая рефлексия и скачивание заметок в TXT.

В каждом разделе есть одно интерактивное задание с инструкцией для группы. Встроенный таймер: 1, 3 или 5 минут. Навигация — кнопками и стрелками клавиатуры. Полноэкранный режим — кнопка в шапке (при поддержке браузером).

## Запуск

Никаких зависимостей или сборки. Откройте `index.html` в современном браузере либо запустите:

```sh
python3 -m http.server 4173
```

Откройте http://localhost:4173. Интернет нужен только для загрузки шрифта Google Fonts и открытия внешних источников. При отсутствии сети применяется системный шрифт, сама презентация работает локально.

Ответы сохраняются в localStorage браузера. Серверной базы, передачи ответов преподавателю и общей статистики нет. При недоступном хранилище можно скачать заметки до закрытия страницы.

## GitHub Pages

В репозитории предусмотрен workflow `.github/workflows/pages.yml`, публикующий сайт при push в `main` или ручном запуске. В GitHub откройте **Settings → Pages → Source → GitHub Actions**. Публикация требует разрешённых Actions и Pages в репозитории.
